# VideoClub Manager

## Descripción

VideoClub Manager es una aplicación de escritorio desarrollada en Java para gestionar la información de un videoclub mediante una interfaz gráfica. Se conecta a una base de datos MariaDB para almacenar y gestionar información relacionada con películas y clientes.

El proyecto forma parte de mi aprendizaje en el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM) y me permite poner en práctica conocimientos de programación orientada a objetos, interfaces gráficas y acceso a bases de datos.

## Tecnologías utilizadas

- **Java:** desarrollo de la lógica de la aplicación.
- **Java Swing:** creación de la interfaz gráfica.
- **JDBC:** conexión entre la aplicación y la base de datos.
- **MariaDB:** almacenamiento y gestión de la información.
- **SQL:** consultas y operaciones sobre los datos.
- **Git y GitHub:** control de versiones y alojamiento del código.

## Funcionalidades

- Gestión de la información de películas y clientes.
- Operaciones CRUD: creación, consulta, modificación y eliminación de registros.
- Conexión a una base de datos MariaDB mediante JDBC.
- Interfaz gráfica de escritorio desarrollada con Java Swing.

## Instalación y ejecución

### Requisitos

- Java JDK.
- Servidor MariaDB.
- Base de datos y tablas necesarias para la aplicación.
- Controlador JDBC de MariaDB.

### Pasos

1. Clona el repositorio:

   ```bash
   git clone https://github.com/brando046/Videoclub-java.git
   ```

2. Abre el proyecto en tu IDE de Java.

3. Configura la conexión a MariaDB con los parámetros correspondientes a tu entorno.

4. Comprueba que la base de datos y las tablas necesarias estén creadas.

5. Ejecuta la clase principal desde tu IDE.

Los pasos de configuración pueden variar según la estructura del proyecto y la forma en que se gestionen las credenciales de conexión.
